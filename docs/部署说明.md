# 部署说明

三步：**装环境 → 建库 + 初始化 → 打开页面**。约 20 分钟。

---

## 1. 装环境

| 必须 | 版本 | 装法 |
|---|---|---|
| Linux | Ubuntu 22.04（其他发行版同理） | — |
| Python | **3.12** | `sudo apt install -y python3.12 python3.12-venv` |
| Node.js | 18+ | `curl -fsSL https://deb.nodesource.com/setup_20.x \| sudo -E bash - && sudo apt install -y nodejs` |
| MySQL | 8.0 | `sudo apt install -y mysql-server` |
| 模型 API Key | OpenAI 协议即可 | 公司网关或官方 Key |

py 依赖下载慢就先 `export PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/`。

---

## 2. 建库 + 初始化

**2.1 建库**（一次）

```sql
CREATE DATABASE open_agent_harness DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'agent'@'%' IDENTIFIED BY '你的数据库密码';
GRANT ALL PRIVILEGES ON open_agent_harness.* TO 'agent'@'%';
FLUSH PRIVILEGES;
```

> 表不用建，服务启动时自动建。

**2.2 装程序**

```bash
git clone https://github.com/cuijiejie/open-agent-harness.git /opt/open-agent-harness
cd /opt/open-agent-harness

sudo PA_DB_MYSQL_PASS='你的数据库密码' \
     PA_LLM_DEEPSEEK_API_KEY='sk-你的模型key' \
     bash deploy/install.sh
```

脚本会：建虚拟环境 → 装依赖 → 构建前端 → 生成 `.env` → 装 systemd → 启动 → 探活。

**2.3 建管理员**

```bash
cd /opt/open-agent-harness
PYTHONPATH=. .venv/bin/python deploy/seed_admin.py
```

**2.4 初始化数据就这些**

| 表 | 内容 |
|---|---|
| `pa_roles` | 2 个角色：**管理员**（`admin`，全部工具）、**公共角色**（`default`，公共工具） |
| `pa_users` | 1 个账号：**admin** |
| `pa_user_roles` | admin → 管理员 |

之后新建用户：不选角色 = 公共角色，不填密码 = `123456`。
