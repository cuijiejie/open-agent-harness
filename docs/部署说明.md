# 部署说明

三步：**装环境 → 建库 + 初始化 → 打开页面**。约 20 分钟。

---

## 1. 装环境

| 必须 | 版本 | 装法 |
|---|---|---|
| Linux | Ubuntu 22.04（其他发行版同理） | — |
| Python | **3.12** | **Miniforge**，见下面 §1.1（不用 venv） |
| Node.js | 18+ | `curl -fsSL https://deb.nodesource.com/setup_20.x \| sudo -E bash - && sudo apt install -y nodejs` |
| MySQL | 8.0 | `sudo apt install -y mysql-server` |
| PostgreSQL | 14+ | `sudo apt install -y postgresql`（**必装**：启动时连不上服务直接退出） |
| Redis（推荐） | 6+ | `sudo apt install -y redis-server`（不装则限流/权限缓存降级） |
| 模型 API Key | OpenAI 协议即可 | 公司网关或官方 Key |

py 依赖下载慢就先 `export PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/`。

### 1.1 装 Miniforge（Python 3.12）

**本部署的 Python 环境用 Miniforge，不用 venv。**

```bash
# aarch64；x86_64 把文件名换成 Miniforge3-Linux-x86_64.sh
curl -fsSLO https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-aarch64.sh
bash Miniforge3-Linux-aarch64.sh -b -p "$HOME/miniforge3"

# 建项目环境（只用 conda-forge 频道）
"$HOME/miniforge3/bin/conda" create -y -n oah \
     --override-channels -c conda-forge python=3.12
"$HOME/miniforge3/envs/oah/bin/python" -V      # 期望 3.12.x
```

装到 `$HOME/miniforge3` 即可；想多用户共用可 `-p /opt/miniforge3`（服务以 root
运行时要相应调整 `CONDA_PREFIX_DIR`）。

细节（为什么选 Miniforge、conda/pip 混用规矩、验收、回滚、踩坑）见
[`Conda环境.md`](Conda环境.md)。

## 2. 建库 + 初始化

**2.1 建库**（一次）

```sql
CREATE DATABASE open_agent_harness DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'agent'@'%' IDENTIFIED BY '你的数据库密码';
GRANT ALL PRIVILEGES ON open_agent_harness.* TO 'agent'@'%';
FLUSH PRIVILEGES;
```

> 表不用建，服务启动时自动建。
> PostgreSQL 也要建库并给 postgres 设口令：`sudo -u postgres psql -c "ALTER USER postgres PASSWORD 'PG密码';" -c "CREATE DATABASE open_agent_harness;"`
> 口令以 `PA_AGENT_PG_PASS` 注入（前缀是 section 名 `AGENT`，写成 `PA_PG_PASS` 不生效）。

**2.2 装程序**

```bash
git clone https://github.com/cuijiejie/open-agent-harness.git /opt/open-agent-harness
cd /opt/open-agent-harness

sudo PA_DB_MYSQL_PASS='你的数据库密码' \
     PA_AGENT_PG_PASS='你的PG密码' \
     PA_LLM_DEEPSEEK_API_KEY='sk-你的模型key' \
     USE_CONDA=1 \
     CONDA_PREFIX_DIR="$HOME/miniforge3" CONDA_ENV=oah \
     bash deploy/install.sh
```

脚本会：装依赖到 conda 环境 → 构建前端 → 生成 `.env` → 装 systemd → 启动 → 探活。

> `USE_CONDA=1` 表示用 Miniforge 的环境、不建 `.venv`。脚本会把
> `PA_INSTALL_USE_CONDA=1`、`PA_INSTALL_CONDA_PREFIX`、`PA_INSTALL_CONDA_ENV`
> 写进 `.env`，以后重跑 `install.sh` 不带参数也会继续用同一个环境。
> 注意 `sudo` 会重置 `$HOME`，所以 `CONDA_PREFIX_DIR` 要写**绝对路径**。

**2.3 建管理员**

```bash
cd /opt/open-agent-harness
PYTHONPATH=. "$HOME/miniforge3/envs/oah/bin/python" deploy/seed_admin.py \
     --password '你的登录密码'
```

**2.4 初始化数据就这些**

| 表 | 内容 |
|---|---|
| `pa_roles` | 2 个角色：**管理员**（`admin`，全部工具）、**公共角色**（`default`，公共工具） |
| `pa_users` | 1 个账号：**admin** |
| `pa_user_roles` | admin → 管理员 |

之后新建用户：不选角色 = 公共角色，不填密码 = `123456`。
